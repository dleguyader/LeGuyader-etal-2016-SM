Le Guyader *et al.* Supplementary material
================

Script and data to reproduce mss Figure S4 for the MS:

Le Guyader, Damien, Cyril Ray, Françoise Gourmelon, and David Brosset. 2017. “Defining High-Resolution Dredge Fishing Grounds with Automatic Identification System (AIS) Data.” *Aquatic Living Resources* 30 (39). https://doi.org/10.1051/alr/2017038.


* Clone or download the repository and 
* Run the "reproduce.Rmd" file.   
* Results are shown in the "reproduce.md" file.
